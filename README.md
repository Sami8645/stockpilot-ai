# StockPilot AI 🤖📈

**Your investments. On autopilot. On Solana.**

StockPilot AI is a hackathon MVP for programmable investing in tokenized stocks.

## What it demonstrates
- Natural-language AI portfolio builder
- Risk-aware portfolio allocation
- Portfolio health score
- Tokenized stock basket UX
- Solana wallet / transaction flow placeholder
- Recurring investment autopilot

## Run locally
This MVP is dependency-free.

Open `index.html` in a browser.

## Demo
Try prompts such as:
- `I have $500. Build me a balanced AI stock portfolio.`
- `Build a low risk portfolio with $1000`
- `Create an aggressive AI portfolio with $500`
